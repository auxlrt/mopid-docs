## Job Description

The Job Description section allows you to create and edit comprehensive job descriptions that provide detailed information about the role, responsibilities, and requirements. This is a crucial section that helps candidates understand the position and its expectations.

## Accessing Job Description

1. Navigate to the Job Management dashboard
2. Click on the "Details" button of any job card
3. The slideover menu will open on the right side of the screen
4. Select "Job Description" from the left navigation menu

### Recommended Structure

A well-structured job description typically includes:

1. **Role Overview**
   - Brief introduction to the position
   - Key responsibilities
   - Team context

2. **Key Responsibilities**
   - Daily tasks
   - Project involvement
   - Team collaboration aspects

3. **Requirements**
   - Technical skills
   - Soft skills
   - Experience level
   - Education requirements

4. **Benefits**
   - Compensation details
   - Perks
   - Growth opportunities

## Editing Job Description

1. Click in the text box to begin editing
2. Use the formatting toolbar to style your content
3. The "Save" button will become active (orange color) when changes are made
4. Click "Save" to update the job description
5. Changes will be reflected immediately across the platform

<Info>
  The job description is pre-filled with the content provided during job posting. You can modify it at any time while the job is active.
</Info>

<Warning>
  Changes to the job description will affect all active job postings and candidate views. Consider the impact on existing applications.
</Warning>

## Best Practices

When writing job descriptions:
- Be specific about requirements
- Use clear, concise language
- Include all essential information
- Avoid discriminatory language
- Highlight unique aspects of the role
- Keep formatting consistent
