## Options

The Options section provides additional management actions for your job posting, including the ability to duplicate or close the job. These actions help you manage the lifecycle of your job requisitions effectively.

## Accessing Options

1. Navigate to the Job Management dashboard
2. Click on the "Details" button of any job card
3. The slideover menu will open on the right side of the screen
4. Select "Options" from the left navigation menu

## Available Options

### Duplicate Job
This option allows you to create a copy of an existing job posting:

1. Click the "Duplicate Job" button
2. Confirm the duplication in the popup dialog
3. You'll be redirected to the Job Posting Flow with pre-filled information
4. Edit the duplicated job details as needed

<Info>
  Duplicating a job creates a new job posting with all the same configurations, allowing you to quickly create similar positions.
</Info>

### Close Job
This option allows you to stop accepting new applications for a job:

1. Click the "Close Job" button
2. Confirm the action in the popup dialog
3. The job status will change to "Closed"
4. The job will no longer accept new applications on the MOPID Job Board

<Warning>
  Closing a job will prevent new applications but won't affect existing candidates in the pipeline.
</Warning>

## Job Status Management

The Options section also displays the current status of your job:

### Active Jobs
- Status: Posted (green)
- Accepting new applications
- Can be modified and managed

### Draft Jobs
- Status: Draft (orange)
- Not yet posted
- Can be edited and modified

### Closed Jobs
- Status: Closed (grey)
- Not accepting new applications
- Can be reopened if needed

## Closing the Details Panel

- Click the "X" button in the top-right corner to close the slideover
- Any unsaved changes will prompt a confirmation dialog

## Quick Actions

You can also access these options from the job card's 3-dot menu:
1. Hover over the job card
2. Click the 3-dot menu icon
3. Select either "Duplicate Job" or "Close Job"
4. Follow the confirmation prompts
