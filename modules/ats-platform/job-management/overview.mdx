## Job Management

The Job Management module provides a centralized platform for managing all job requisitions, allowing recruiters and hiring managers to create, modify, and track job postings effectively. This module serves as the foundation for your recruitment process, enabling you to configure job details, screening criteria, and hiring pipelines.

## Key Features

- Create and manage job postings
- Configure job details and requirements
- Set up screening questions
- Customize hiring pipelines
- Import candidates from various sources
- Duplicate or close job postings as needed

## Job Management Dashboard

The dashboard provides a comprehensive view of all job requisitions with the following elements:

### Active Jobs Overview
- Total count of active job postings
- Search functionality to find specific jobs by title
- Create Job button to initiate new job postings

### Job Cards
Each job card displays essential information:
- Job Role and Domain
- Location, Salary, and Timing details
- Candidate statistics:
  - Total Candidates Count
  - New Candidates Count
- Job Status indicators:
  - Posted (green)
  - Draft (orange)
  - Closed (grey)
- Action buttons:
  - Details button for active jobs
  - 3-dot menu for additional options

### Quick Actions
- Duplicate existing jobs
- Close job postings
- Edit job details

Each tab provides specific functionality to help you manage different aspects of your job requisitions effectively.

## Job Status Management

Jobs can exist in three states:
- **Posted**: Active jobs accepting applications (green status)
- **Draft**: Jobs pending approval or completion (orange status)
- **Closed**: Jobs no longer accepting applications (grey status)

<Info>
  When closing a job, the system will prompt for confirmation and stop accepting new applications on the MOPID Job Board.
</Info>

## Candidate Import

The module supports importing candidates through:
- File upload (up to 250MB)
- URL-based import
- Multiple source integration

<Warning>
  Deleting an imported file will also remove all candidate data added through that file from the candidate list view.
</Warning>
